# Progress Records

Keep enough evidence here to reproduce your claims later. Suggested tracked files:

- a copy of `weekly_log.template.md` filled in each Friday;
- `environment-<machine>.txt` from `pip freeze`;
- `hardware-<machine>.json` from `scripts/doctor.py --json`;
- small CSV summaries and plots from experiments.

Do not commit access tokens, private employer data, datasets, model weights, raw
videos, or profiler capture binaries.
