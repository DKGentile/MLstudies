# Progress records

Use `learning_log.csv` for facts and `WEEKLY_RETROSPECTIVE.md` for judgment.
The log is intentionally plain text so it remains useful in git diffs.

For each practice problem, record the pattern you selected, whether the first
attempt passed, elapsed active minutes, and the mistake category. Useful mistake
categories are `model`, `invariant`, `edge-case`, `syntax`, `complexity`, and
`debugging`.

A strong week is not an unbroken row of passes. It is a week in which repeated
mistakes become named and then stop repeating.
