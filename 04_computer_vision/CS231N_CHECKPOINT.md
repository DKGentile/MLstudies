## Weeks 5–6 — Assignment 1

[Official Assignment 1](https://cs231n.github.io/assignments2026/assignment1/)

- [ ] k-nearest-neighbor classifier
- [ ] vectorized softmax classifier
- [ ] two-layer neural network
- [ ] higher-level image features
- [ ] fully connected network

For each section, write down tensor shapes, the slowest avoidable loop, and one
failed test or gradient check. Compare the softmax and two-layer implementations to
your `03_ml_fundamentals` code without copying either implementation into the
other.
